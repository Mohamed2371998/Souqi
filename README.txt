سوقي — نسخة أوفلاين
====================
1. فك ضغط المجلد كامل في أي مكان على جهازك.
2. افتح ملف index.html بالضغط عليه مرتين (Chrome / Edge / Firefox).
3. يشتغل بدون إنترنت وبدون تنصيب أي برامج.

ملاحظات:
- لازم يبقى ملف index.html ومجلد assets مع بعض في نفس المكان.
- الخطوط العربية تتحمل من الإنترنت؛ بدون نت يشتغل بخط النظام بشكل طبيعي.
- صفحة الدفع تعمل كعرض فقط لأن بوابات الدفع تحتاج سيرفر وإنترنت.
